# Portfolio

이 폴더는 LLM 엔지니어 커리어를 목표로 한 개인 포트폴리오 웹사이트의 기본 틀(템플릿)입니다.

## 구성
- `index.html` : 포트폴리오 메인 페이지 (Hero, About, Roadmap, Skills, Projects, Certifications, Contact)
- `style.css` : 밝고 미니멀한 디자인 스타일시트

## 사용 방법
1. `[대괄호]`로 표시된 placeholder 텍스트를 실제 내용으로 채웁니다.
   - 이름, 자기소개, GitHub 링크, 이메일
   - Skills 목록
   - Certifications (보유 / AI-데이터 관련 / 준비 중)
2. Projects 섹션에는 `Coding LLM Comparison`, `Korean News LLM Classification` 등
   실제 프로젝트 저장소 링크를 연결합니다.
3. GitHub Pages로 배포하려면 저장소 Settings > Pages에서 이 폴더(또는 루트)를 소스로 지정합니다.

## 디자인 원칙
- 밝고 미니멀한 톤
- 이력서는 PDF 다운로드가 아닌 웹 콘텐츠 형태로 제공
- Certifications 섹션은 현재 비어있는 placeholder 상태 (추후 업데이트 예정)
